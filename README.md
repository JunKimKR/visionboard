# 비전보드

내 사진으로 만드는 비전보드 웹앱. 폰·PC 브라우저에서 열고, 홈 화면에 앱처럼 추가할 수 있다.

## 기능
- 주제별 보드 여러 개 (예: 돈 / 건강 / 여행)
- 보드마다 큰 다짐 문구, 사진마다 짧은 문구
- 핀터레스트식 자동 정렬, 꾹 눌러 끌어서 순서 변경
- 전체화면 슬라이드쇼 (재생 중 화면 꺼짐 방지)
- 폰 잠금화면 / PC 배경화면용 이미지 만들기
- 백업 파일 내보내기 / 불러오기 (기기 간 이동)
- PC: 파일 끌어다 놓기, Ctrl+V 붙여넣기로 사진 추가

## 저장 방식 (중요)
- 사진은 **이 기기 브라우저 안(IndexedDB)에만** 저장된다. 서버로 안 올라가서 다른 사람은 못 본다.
- 그래서 폰과 PC는 서로 따로다. 옮기려면 백업 파일을 쓴다.
- 브라우저의 "방문 기록/사이트 데이터 삭제"를 하면 사진도 지워진다. 가끔 백업할 것.
- 아이폰: Safari 탭과 "홈 화면에 추가"한 앱은 저장소가 따로다. 홈 화면에 추가한 뒤 그 아이콘에서 사용할 것.

## 배포 (GitHub Pages)
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → 브랜치 선택, 폴더 `/ (root)` → Save.
몇 분 뒤 `https://<아이디>.github.io/visionboard/` 에서 열린다.

## 로컬 실행
```
python3 -m http.server 8000
```
→ http://localhost:8000

빌드 과정 없음. `vendor/Sortable.min.js`는 SortableJS 1.15.6 (MIT).
